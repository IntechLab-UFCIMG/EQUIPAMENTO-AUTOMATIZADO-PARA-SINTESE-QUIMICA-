# EQUIPAMENTO-AUTOMATIZADO-PARA-SINTESE-QUIMICA-
Desenvolvimento e montagem de aparato experimental para síntese química.

O objetivo deste projeto é desenvolver um equipamento destinado à realização automatizada de procedimentos de síntese química, permitindo a obtenção de substâncias químicas de forma automatizada.
O projeto tem como foco principal o desenvolvimento de um sistema modular, baseado em tecnologias de código aberto (open source) e na utilização de dispositivos e componentes de fácil acesso e baixo custo.
Este trabalho integra o projeto de doutorado da mestre Fabiane Carla Lopes, discente do Programa de Pós-Graduação Multicêntrico em Química de Minas Gerais, na Universidade Federal de Ciência e Inovação de Minas Gerais.
